Uber Ride Analytics Dashboard
Project Overview

This project is an Uber Ride Analytics Dashboard created to analyze Uber booking, revenue, distance, and ride performance data.

The dashboard provides a simple visual view of important business information such as completed bookings, total distance, revenue, lost bookings, monthly performance, vehicle-wise revenue, and customer/driver ratings.

Dashboard Analysis
1. Booking Analysis

The Booking Completed By Month chart shows the number of completed rides for each month.

This helps to understand:

Monthly booking trends
High and low booking months
Changes in ride demand throughout the year
2. Revenue Analysis

The Revenue chart compares revenue generated by different vehicle types.

The dashboard shows revenue from:

Auto
Bike
Go Mini
Go Sedan
Premier Sedan
Uber XL

This helps identify which vehicle categories generate more revenue.

3. Monthly Revenue

The Monthly Revenue chart shows revenue for each month.

It can be used to compare monthly performance and identify periods with higher or lower revenue.

4. Location Analysis

The dashboard displays the most common pickup and drop locations.

Top Pickup Location: Khandsa
Top Drop Location: Ashram

This helps understand important travel locations and customer movement patterns.

5. Ride Status

The dashboard provides information about different ride statuses:

Completed – Rides that were successfully completed.
Cancelled – Rides cancelled for any reason.
Incomplete – Rides that could not be completed.

This helps analyze booking success and lost rides.

6. Ratings Analysis

The dashboard shows ratings from both customers and drivers.

Customer Rating: 4.40
Driver Rating: 4.23

These ratings provide an overview of the overall ride experience.

Tools Used
Power BI – Dashboard development and visualization
Power Query – Data cleaning and transformation
Excel / CSV – Data source and data preparation
DAX – Measures and calculations
Project Objectives

The main objectives of this project are:

Analyze Uber booking data.
Track revenue and distance.
Analyze monthly booking trends.
Compare revenue across vehicle types.
Identify important pickup and drop locations.
Analyze completed, cancelled, and incomplete rides.
Monitor customer and driver ratings.
Present the results through an interactive dashboard.

Conclusion

The Uber Dashboard provides a simple and interactive way to understand ride performance and business activity. It combines booking, revenue, distance, location, vehicle, and rating information into one dashboard, making it easier to analyze overall Uber ride performance and identify important trends.
